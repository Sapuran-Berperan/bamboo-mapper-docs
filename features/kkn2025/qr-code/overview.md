# Fitur QR Code

## Pendahuluan

QR Code Bamboo Mapper adalah fitur yang memungkinkan Anda membuat kode QR unik untuk setiap bambu yang dipetakan. Dengan QR Code, informasi detail tentang bambu dapat diakses dengan mudah hanya dengan memindai kode menggunakan aplikasi.

### Mengapa QR Code Berguna?

- **Akses Cepat**: Dapatkan informasi bambu secara instan tanpa perlu mencari manual
- **Identifikasi Fisik**: Pasang QR Code di lokasi bambu untuk identifikasi yang mudah
- **Berbagi Informasi**: Bagikan informasi bambu kepada tim lain dengan mudah
- **Tracking**: Lacak bambu yang telah dipetakan dengan label fisik

---

## Cara Menggunakan QR Code

### Langkah 1: Buat Marker Baru

1. Buka [dashboard Bamboo Mapper](https://bamboomapper.sapuranberperan.cloud)
2. Masuk ke menu **Markers**
3. Klik tombol **Tambah Marker** atau **Create Marker**
4. Isi informasi bambu yang ingin dipetakan:
   - Nama bambu
   - Jenis/strain bambu
   - Jumlah bambu
   - Koordinat lokasi
   - Foto bambu
   - Informasi pemilik
   - Deskripsi tambahan
5. Klik **Simpan**

### Langkah 2: Generate QR Code

1. Daftar marker akan ditampilkan di dashboard
2. Cari marker yang ingin dibuatkan QR Code
3. Klik tombol **QR Code** pada baris marker tersebut
4. QR Code akan otomatis dibuat dan ditampilkan dalam preview

### Langkah 3: Download QR Code dan Gunakan Template

1. Klik tombol **Download** pada preview QR Code
2. QR Code akan terunduh dalam format PNG
3. Buka template yang telah disediakan: [twb.nz/bamboo-mapper-qr-code](https://twb.nz/bamboo-mapper-qr-code)
4. Pilih QR Code yang sudah disediakan
5. Pastikan seluruh QR Code terlihat dengan jelas dan tidak terpotong
6. Download templatenya

### Langkah 4: Cetak dan Pasang

1. Cetak template yang sudah berisi QR Code
2. Laminkan atau lapis agar tahan cuaca
3. Pasang di lokasi bambu yang sesuai
4. Pastikan QR Code terlihat jelas dan mudah diakses untuk dipindai

### Langkah 5: Scan QR Code

1. Gunakan kamera bawaan smartphone atau aplikasi pemindai QR Code
2. Arahkan kamera ke QR Code hingga terdeteksi
3. Anda akan diarahkan ke halaman web yang menampilkan informasi bambu

---

## Informasi yang Ditampilkan

Setelah QR Code dipindai, informasi berikut akan ditampilkan:

| Informasi | Deskripsi |
|-----------|-----------|
| **Nama Bambu** | Nama unik untuk identifikasi bambu |
| **Jenis/Strain** | Varietas atau jenis bambu |
| **Jumlah** | Jumlah bambu di lokasi tersebut |
| **Koordinat** | Latitude dan longitude lokasi bambu |
| **Foto** | Foto bambu yang diupload |
| **Pemilik** | Nama dan kontak pemilik bambu |
| **Deskripsi** | Informasi tambahan tentang bambu |

## FAQ

### Apa yang terjadi jika QR Code rusak atau hilang?

Anda dapat membuat ulang QR Code kapan saja melalui dashboard. QR Code dibuat berdasarkan short code yang unik untuk setiap marker, sehingga QR Code baru akan tetap valid untuk marker yang sama.

### Apakah QR Code bisa digunakan kembali?

Ya, QR Code tetap valid selama marker masih ada dalam sistem. Anda dapat mencetak ulang QR Code kapan saja jika diperlukan.

### Bagaimana cara memindai QR Code?

Gunakan kamera bawaan smartphone untuk memindai. Anda akan diarahkan ke halaman web untuk melihat informasi bambu.

### Apakah QR Code memerlukan koneksi internet?

Untuk memindai QR Code, koneksi internet diperlukan untuk mengambil informasi bambu terbaru dari server. Pastikan perangkat terhubung ke internet sebelum memindai.

## Tips

- Gunakan kertas berkualitas baik dan lakukan laminasi untuk ketahanan jangka panjang
- Pasang QR Code pada ketinggian yang mudah dijangkau untuk dipindai
- Hindari memasang QR Code di tempat yang terkena sinar matahari langsung secara berlebihan
- Periksa secara berkala kondisi QR Code yang terpasang
